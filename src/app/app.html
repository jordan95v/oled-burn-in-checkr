🖥️ OLED Burn-in Checkr

A simple web application to test OLED screens for burn-in issues.
If you find this project useful, please consider leaving a star here ⭐

❓ How to use ?

This application is straightforward to use. Just follow these steps:

  • Choose a color from the card on the right (or below on smaller screens).
  • Click the fullscreen button to test your screen.
  • Press Esc to exit fullscreen mode.

You can also use the F11 key to toggle fullscreen mode in most browsers.

🎨 Choose a color

Click on a color below to select it. The selected color will be used for the burn-in test.
